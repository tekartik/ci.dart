# repo_support

App flutter utils repo support

```
dart run tool/run_ci.dart

```

Run a workflow locally with act (ubuntu jobs, see
[doc/ci_on_demand_testing.md](../doc/ci_on_demand_testing.md)):

```
dart run tool/act_example_pub_get.dart              # minimal example (example/act_pub_get)
dart run tool/act_run.dart local_dart_default       # a ci.dart workflow
```
